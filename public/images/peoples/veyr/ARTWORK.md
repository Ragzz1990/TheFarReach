# Veyr artwork drop-in slots

The site uses local SVG placeholders until finished artwork is available. Add final artwork here with these exact names:

- `portrait.webp`
- `fox.webp`
- `wolf.webp`
- `sighthound.webp`
- `hound.webp`
- `jackal.webp`
- `arctic.webp`
- `culture.webp`
- `homeworld.webp`

Keep the matching SVG files as fallbacks. The dossier automatically prefers a WebP file when present.
